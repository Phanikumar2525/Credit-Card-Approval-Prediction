# 💳 Credit Card Approval Prediction

A Machine Learning-based web application that predicts whether a credit card application is likely to be approved based on applicant information. The model is trained using historical credit card application data and deployed using Flask.

🚀 **Live Now:** https://credit-card-approval-j1ei.onrender.com/

## 📌 Project Overview

This project uses Machine Learning algorithms to predict credit card approval decisions based on customer details such as income, education, employment, housing, and family status.

The application provides a simple web interface where users can enter applicant details and instantly receive a prediction.

## ▶️ How to Run the Project

### Clone the repository

```bash
git clone https://github.com/Phanikumar2525/Credit_Card_Approval_Prediction.git
```

### Navigate to the project folder

```bash
cd Credit_Card_Approval_Prediction
```

### Install dependencies

```bash
pip install -r requirements.txt
```

### Run the Flask application

```bash
python app.py
```

### Open the application

```
http://127.0.0.1:5000/
```
